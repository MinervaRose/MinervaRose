### A notebook of working questions

I use this space to make technical investigations inspectable. Here you'll find code, notebooks, working systems, visualisations, research artefacts and the decisions behind them. I'm interested in what a model or a dataset can reveal, but equally in what the evidence *doesn't* establish.

The [portfolio](https://minervarose.github.io/) presents my professional work and background. This observatory follows the experiments themselves.

### On the observing desk

**AI decision systems.** How should evidence, uncertainty and escalation be handled when analytical components contribute to consequential decisions?

**Structure in scientific signals.** What can alternative representations reveal about acoustic patterns, trajectories and anomalies, and where might they mislead us?

**Traceable investigation.** How can software preserve the path from an observation to an interpretation, instead of presenting only a polished answer?

A small selection of public projects. Each follows a different question, with its own methods and limitations.

- **01 / Aerospace AI** · [Industry-Integrated AI Systems Synthesis](https://github.com/MinervaRose/industry-integrated-ai-systems-synthesis)  
  Anomaly triage, auditable decision-support architecture and human oversight.
- **02 / Scientific signals** · [Bioacoustic Topology](https://github.com/MinervaRose/bioacoustic-topology)  
  Birdsong features, manifold representations, motif structure and dynamical perspectives.
- **03 / Space data** · [Exoplanet Discovery Observatory](https://github.com/MinervaRose/exoplanet-discovery-observatory)  
  Data exploration and Tableau visualisation using NASA Exoplanet Archive data.
- **04 / Audit analytics** · [BeLedgerReady](https://github.com/MinervaRose/BeLedgerReady)  
  Deterministic checks, explainable assistance and evidence-oriented financial review.
- **05 / Developer tooling** · [Clues](https://github.com/MinervaRose/clues)  
  Evidence-oriented exception investigation in Python, with tests and diagnostic reports.

### How I work

```text
OBSERVE    Python · SQL · Jupyter · exploratory analysis
MODEL      Machine learning · LLM systems · signal representations
EXAMINE    Evaluation · traceability · human review · limitations
DOCUMENT   Reproducible notebooks · technical reports · versioned artefacts
```

Experiments and prototypes are labelled as such. A promising representation is a starting point for investigation, not automatically a scientific conclusion.
