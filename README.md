### Welcome to the Observatory

My work is rooted in artificial intelligence and data science, but my curiosity has never been confined to a single discipline.

I enjoy exploring unfamiliar questions, experimenting with ideas and building things along the way. Some become substantial projects; others are smaller investigations, prototypes or simply things I wanted to try.

This is where I share a selection of those explorations. My [portfolio](https://minervarose.github.io/) tells the broader professional story. Here, you can open the repositories and discover the work for yourself.

### How I work

```text
OBSERVE    Python · SQL · Jupyter · exploratory analysis
MODEL      Machine learning · LLM systems · signal representations
EXAMINE    Evaluation · traceability · human review · limitations
DOCUMENT   Reproducible notebooks · technical reports · versioned artefacts
```

Experiments and prototypes are labelled as such. A promising representation is a starting point for investigation, not automatically a scientific conclusion.
